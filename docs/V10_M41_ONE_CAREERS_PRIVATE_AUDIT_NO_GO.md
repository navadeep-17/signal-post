# M41 — Private archived-source evidence gate for one M40 careers candidate

**Decision: NO-GO under the stricter exact-org homepage test. NO NEW CLAIMS, NO MERGE.**

## Scope

M40's fully offline replay of the earlier consumed 300-company V8 artifacts found six existing verified homepages with a careers link; five companies had existing careers claims, and one different company was a candidate for new company-level *careers-link presence*. M41 deliberately audits only that one candidate. It does not search the web, fetch a company page, publish a claim, merge anything, or measure Builderr's official score.

Original evidence consists solely of SHA-pinned, previously consumed M19-A/M19-B/M20-A GitHub Actions ZIP archives. The exact company ID and site URL are available **only in temporary private Actions runner memory** and are never logged/exported.

**Important distinction:** The original V8 retained page had a publishable existing identity assessment; M41 imposes the stronger additional requirement that the **archived first-party homepage text explicitly present the target nine-digit Norwegian organisation number**. It does not. That is **absence of proof in the retained excerpt**, not proof that the candidate belongs to another company. The current homepage may contain better evidence, but no fresh request was authorized or executed in this archived review.

A source-provenance/canonical pass **is not an exact-company positive publication decision**. The automated run is an additional code-and-archive audit, not independent human verification or evidence of a live site.

## Implementation

- `src/norway_company_agent/v10_m41_private_careers_audit.py`: zero-network, fixed-schema in-memory exact-org, wrong-org, HTTPS/same-host, hash, date, source-link and validator audit; outputs flags/counters only. It never returns names, org numbers or websites.
- `scripts/run_v10_m41_private_careers_audit.py`: verifies all three original ZIP checksums, frozen manifests, same 300 companies, and M40 original five baseline careers companies before selecting exactly one net-new candidate; prints no source content.
- `.github/workflows/v10-m41-private-careers-evidence.yml`: experimental-branch push only, archived GitHub artifacts only, no provider credentials, company HTTP, publication or plaintext artifacts.
- `tests/test_v10_m41_private_careers_audit.py`: synthetic valid proof, missing/wrong organisation number, wrong host/hash, bad timestamp, duplicate and cross-company regressions.
